Timer House privacy policy

Last updated 11 November 2026.

The Timer House uploader is a private tool used only by the owner of the Timer House YouTube channel to upload that channel's own videos. It is not offered to anyone else.

YouTube API Services

  • The Timer House uploader uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service. Google's handling of your information is described in the Google Privacy Policy.
  • It signs in with the channel owner's Google account through Google's own sign-in, and uses the YouTube Data API only to upload Timer House videos, set their thumbnails, add them to playlists and read the channel's view counts.

What data it uses, stores and shares

  • It uses only the Timer House channel's own data: its videos, playlists and view counts. It does not collect, store or share data about any other person or channel, and it uses no cookies or tracking.
  • The sign-in key and the list of uploaded video IDs and view counts are kept only on the owner's own computer. Nothing is sold or shared with anyone.
  • Its use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Taking back access and deleting data

  • Access can be taken back at any time on the Google security settings page: https://security.google.com/settings/security/permissions.
  • Stored data (the sign-in key and the saved view counts) is deleted from the owner's computer within 7 days of access being taken back, or at any time on request to the address below.

Watching Timer House videos on YouTube is covered by Google's privacy policy.
