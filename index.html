What we do

Web applications and games

Browser-based software that runs as well on a phone as on a desktop, including real-time 3D built with Three.js and Unity. No installs, no app store between the work and the people using it.

Online services

Accounts, cloud saves, chat and multiplayer backends, self-hosted on rented servers with automatic HTTPS, nightly backups and admin pages for the people who run them.

Tooling and automation

Internal tools that turn a slow, error-prone process into a clear one: trackers, validators, generators and AI-assisted workflows built around how the work is actually done.

About

No Limit Nexus is a one-person studio. Projects are built in the open where that makes sense and kept private while they are still being shaped; several are in development and not yet shown here.

The work favours plain, dependable choices: standard web technology, small servers, code that one person can read and run years later. Details and demonstrations of current work are available on request.
